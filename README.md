# ScreenInk

Windowsの画面をそのままキャンバスにして、Surfaceペンで書き込むアプリ。

## インストール

[Releases](https://github.com/xxx83482904-glitch/ScreenInk/releases) から `ScreenInk-Setup-x.y.z.exe` をダウンロードして実行します
（x64 と ARM の Surface の両方に対応。機種別の `-x64` / `-arm64` もあります）。管理者権限は不要です。

**初回インストール時に「Windows によって PC が保護されました」（SmartScreen）と表示されます。**
コード署名をしていないためです。「詳細情報」→「実行」で進めてください。署名は今のところ対象外です。

起動すると画面右端に小さなランチャーが出ます（上の「•••」をつまむと移動できます）。タスクトレイにも常駐します。
ランチャーのボタンは「画面＋一時停止」（今の画面を止めて書く）と「画面＋ペン」（重ねて書く）の2つです。保存先を開く、アップデートの確認、終了はトレイのメニューにあります。

### ソースから動かす（開発用）

1. [Node.js](https://nodejs.org/)（LTS）を入れる
2. `start.bat` をダブルクリック（初回だけ Electron のダウンロードで数分かかります）

## 使い方

| やりたいこと | ランチャー | キーボード |
|---|---|---|
| 今の画面を止めて書く | 画面＋一時停止 | Ctrl+Alt+S |
| 動いている画面に重ねて書く | 画面＋ペン | Ctrl+Alt+D |
| 書く ⇔ 下のアプリを操作（重ね書き中） | ツールバー「操作」／ランチャーの「画面＋ペン」 | Ctrl+Alt+A |
| 閉じる（書き込みは消えます） | ✕ | Esc / Ctrl+Alt+X |

Esc は、何かを選択している間はまず選択を外します。

- ペンは筆圧で太さが変わります。ペンの尻（消しゴム側）かサイドボタンを押しながら書くと消しゴムになります。
- ペンは常に書く、指は常に操作です（指1本では書けません）。ペンを使っている間と直後は、手のひらや指のタッチは無視されます。
- 「保存」を押すとメニューが出ます。「保存」は PNG をデスクトップに保存し（`ScreenInk_日付_時刻.png`）、同時にクリップボードにもコピーします。「コピーのみ」はファイルを作らず、クリップボードにだけコピーします（そのまま貼り付け可）。
- 「静止」「ライブ」ボタンは、書き込みを残したままモードを切り替えます。
- マルチモニターでは、マウスカーソルのある画面が対象です。
- ツールバー内のキー: Ctrl+Z 戻す / Ctrl+Y 進む / Ctrl+S 保存 / Ctrl+Shift+C 画面をコピーのみ / Ctrl+C 選択をコピー / Ctrl+D 選択を複製 / Ctrl+V 貼り付け / Delete 削除 / P ペン / H マーカー / E 消しゴム / V 選択 / R 定規

## 拡大縮小と無限キャンバス（静止モード）

- 2本指のピンチで拡大縮小、2本指のドラッグで移動します。
- 縮小するとキャプチャの外側に白紙が広がり、そこにも書けます。キャプチャは白紙の上に置かれた1枚の画像です。
- 線はベクターで持っているので、拡大してもぼやけません。消しゴムは線を分割して消します。
- ツールバーの「全体」（Ctrl+1）で書き込みと画像のすべてを表示、「100%」（Ctrl+0）で等倍に戻します。
- マウスの場合: Ctrl+ホイールで拡大縮小、ホイールで移動、中ボタンのドラッグか Space+ドラッグで移動。
- ライブモードは等倍の重ね書きのままです（ピンチしても拡大しません）。

## 貼り付けと画像（静止モード）

- クリップボードの画像を Ctrl+V かツールバーの「貼付」で貼り付けます。位置は今見えている範囲の中央です。
- 「＋撮影」で別の画面をもう1枚撮れます。書き込み画面がいったん隠れるので、撮りたい画面を出してから
  ランチャーの赤い枠のボタン（または Ctrl+Alt+S）を押してください。今ある画像の右隣に並びます。
- 画像も線も「もの」として選択できます。選択すると青い枠が出て、枠の中をドラッグで移動、四隅で拡大縮小、
  メニューの「削除」か Delete キーで削除できます。ペン・指・マウスのどれでも掴めます。
- 選び方: 指でタップ（線・貼り付けた画像）、またはツールバーの「選択」（V）でクリック／囲んで複数選択。
  最初に撮った画面そのものは、うっかり動かさないよう「選択」ツールでクリックしたときだけ選択されます。
- 何もない所をタップするか Esc で選択が外れます。どの操作も「戻す」で取り消せます。
- 画像は常に線の下に描かれます。テキストの貼り付けには未対応です。

## インクジェスチャー（ペンだけで消す・選ぶ）

Microsoft Journal にならった、道具を持ち替えずにペンだけで行う操作です。「ペン」ツールで書いた線にだけ働きます。

| 書き方 | 起きること |
|---|---|
| 線や貼り付けた画像の上を、素早くぐしゃぐしゃと往復する | その下のものが消える（スクラッチアウト） |
| 線や貼り付けた画像を、ぐるっと囲む | 囲んだ瞬間に中のものが選択される（投げ縄） |
| 線や貼り付けた画像の上で、ペンを動かさず 0.5 秒押す | それが選択される。押したまま動かすと移動 |
| 指でタップ | 線や貼り付けた画像を選択。何もない所なら選択を外す |

選択したあとは、枠の中をドラッグで移動、四隅で拡大縮小、メニューで「コピー」「複製」「削除」ができます（Ctrl+C / Ctrl+D / Delete）。
「複製」は少しずらした位置に同じものを作り、複製した側が選択されるので、そのまま動かせます。
コピーしたものは Ctrl+V で線のまま貼り付けられ、ほかのアプリには画像として貼り付けられます。

普通の線が勝手に消えたり選択されたりしないよう、判定は控えめにしてあります。

- 消す・囲む対象が下に無ければ、ぐしゃぐしゃも丸もそのまま線として残ります。
- スクラッチアウトは、2往復半以上の素早い往復で、線の6割以上を覆ったときだけ働きます。
  長い線の一部をこすっただけ、1回なぞっただけ、ゆっくりした往復では消えません。
- 囲んで選択されるのは、書いてから1秒以上たったものだけです（書いた直後に丸で囲む書き込みを邪魔しません）。
  丸を書きたかったのに選択になったときは、メニューの「線として残す」か「戻す」で丸が線として残ります。
- 最初に撮った画面そのものは、ジェスチャーでは消えも選択されもしません。
- どの操作も「戻す」（Ctrl+Z）で取り消せます。

しきい値を変えたいときは `overlay.js` の `HOLD_MS` / `LASSO_MIN_AGE` / `SCRATCH_SPEED` と、`ink-geom.js` の
`isScratch` / `scratchTargets` / `isLoop` を調整してください。

## 定規とパースのガイド線（静止・重ね書きの両方）

**定規**（ツールバー「定規」または R キー）
- 画面の中央に定規が出ます。定規の縁の近く（または定規の上）からペンやマウスで書くと、縁に沿ったまっすぐな線になります。
  定規に沿って書いた線は、往復してもぐしゃぐしゃ消しや囲み選択にはなりません。
- 指1本で移動、指2本で移動と回転（どちらか1本が定規に乗っていれば回ります）。0°・45°・90° などの近くでは吸い付きます。角度は定規の中央に出ます。
  ペンを使った直後でも、指の接触が大きくても、定規は指で動かせます。ペンで書いている最中だけは動きません（押さえたまま引けます）。
- マウスでは、定規の上をドラッグで移動、ホイールで 1° ずつ回転します。
- 定規は画面に固定で、拡大縮小しても大きさは変わりません。保存した画像には入りません。

**パース**（ツールバー「パース」→ 1点透視／2点透視／3点透視）
- 消失点から放射状のガイド線と地平線（赤）を表示します。線の補正はしないので、ガイドに沿って手で書きます。
- 消失点の丸は、指・ペン・マウスのどれでもドラッグで動かせます。撮った画面に貼り付いていて、拡大縮小や移動に付いてきます。
- 「ガイドを消す」で消えます。保存した画像には入りません。

## テスト

- `npm test` … 幾何計算とジェスチャー判定の単体テスト
- `npm run test:e2e` … 実際の画面を Electron で開き、ペン・指・マウスの入力を合成して確認します。
  `SCALE=1.5` を付けると拡大率 150% を模擬します。
- `npm run test:main` … 実際のアプリを起動し、キャプチャの大きさ・位置、モード切り替え、追加撮影を確認します
  （数秒間、全画面の書き込み画面が出ます）。Surface ではまずこれを実行すると、拡大率によるずれの有無が分かります。
- `npm run test:perf` … Surface 相当の画素数で、線をたくさん書いたときの1コマの描画時間を測ります。
- 筆圧・ペンのボタン・実際の指の操作は、実機で手を動かして確認してください。

## アップデート

- 起動して数秒後に、新しいバージョンがあるか自動で確認します。見つかるとお知らせの画面が出て、ランチャーのつまみに赤い印が付きます。
- 手動で確認するには、トレイのメニュー「アップデートを確認…」を押します。
- 「ダウンロード」を押すと進み具合が表示され、終わると「再起動して更新」で新しい版に切り替わります。
  「あとで」を選んだ場合は、次にアプリを終了したときに更新されます。
- 更新は GitHub Releases から取得します（electron-updater）。ソースから動かしているときは確認できません。

## ペンのボタンに割り当てる

「設定 → Bluetoothとデバイス → ペンとWindows Ink」でペンのショートカットボタンに ScreenInk を割り当てると、
ペンのボタンを押すだけでキャプチャして書き始められます（起動中にもう一度呼ばれると即キャプチャする作りです）。
インストール先は `%LOCALAPPDATA%\Programs\ScreenInk\ScreenInk.exe` です。

## リリースの出し方（開発者向け）

1. `npm version patch`（または `minor`）で `package.json` の version を上げる。タグ `vX.Y.Z` が作られます。
2. `git push --follow-tags` でタグを push する。
3. GitHub Actions（`.github/workflows/release.yml`）が Windows 用の x64 / arm64 インストーラーをビルドし、
   `latest.yml` と一緒にその版の Release に公開します。タグと version が食い違っているとビルドは止まります。
4. インストール済みのアプリは、次の起動時（または「アップデートを確認」）でこの Release を見つけます。

- **このリポジトリは public である必要があります。** private のままだと、アプリにトークンを埋め込まない限り
  Release を取得できず、アップデートの確認が 404 で失敗します。
- 手元でインストーラーを作るだけなら `npm run dist`（`dist` フォルダに出力、公開はしない）。
  `npm run pack` はインストーラーにせず `dist\win-unpacked` に展開します。
- コード署名はしていません。初回インストール時に SmartScreen の警告が出ます（上の「インストール」を参照）。

## 調整

- ショートカット: `main.js` 冒頭の `KEYS`
- 色・太さ: `overlay.html` のボタン（`data-color` / `data-size`）
- キャプチャに自分のツールバーが写り込む場合: `main.js` の `HIDE_WAIT_MS` を大きく
