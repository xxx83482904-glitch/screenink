# ScreenInk

Windowsの画面をそのままキャンバスにして、Surfaceペンで書き込むアプリ。

## 起動

1. [Node.js](https://nodejs.org/)（LTS）を入れる
2. `start.bat` をダブルクリック（初回だけ Electron のダウンロードで数分かかります）

起動すると画面右端に小さなランチャーが出ます（上の「•••」をつまむと移動できます）。タスクトレイにも常駐します。

## 使い方

| やりたいこと | ランチャー | キーボード |
|---|---|---|
| 今の画面を止めて書く | 静止で書く | Ctrl+Alt+S |
| 動いている画面に重ねて書く | 重ねて書く | Ctrl+Alt+D |
| 書く ⇔ 下のアプリを操作（重ね書き中） | ツールバー「操作」／ランチャー「書く」 | Ctrl+Alt+A |
| 閉じる（書き込みは消えます） | ✕ | Esc / Ctrl+Alt+X |

- ペンは筆圧で太さが変わります。ペンの尻（消しゴム側）かサイドボタンを押しながら書くと消しゴムになります。
- ペンを使っている間は、手のひらや指のタッチは無視されます。
- 「保存」で PNG を `ピクチャ\ScreenInk` に保存し、同時にクリップボードにもコピーします（そのまま貼り付け可）。
- 「静止」「ライブ」ボタンは、書き込みを残したままモードを切り替えます。
- マルチモニターでは、マウスカーソルのある画面が対象です。
- ツールバー内のキー: Ctrl+Z 戻す / Ctrl+Y 進む / Ctrl+S 保存 / P ペン / H マーカー / E 消しゴム

## exe にする

`npm run pack` で `dist` フォルダに ScreenInk.exe ができます。
このexeを「設定 → Bluetoothとデバイス → ペンとWindows Ink」でペンのショートカットボタンに割り当てると、
ペンのボタンを押すだけでキャプチャして書き始められます（起動中にもう一度呼ばれると即キャプチャする作りです）。

## 調整

- ショートカット: `main.js` 冒頭の `KEYS`
- 色・太さ: `overlay.html` のボタン（`data-color` / `data-size`）
- キャプチャに自分のツールバーが写り込む場合: `main.js` の `HIDE_WAIT_MS` を大きく
