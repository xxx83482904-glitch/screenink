# ScreenInk

Windowsの画面をそのままキャンバスにして、Surfaceペンで書き込むアプリ。

## 起動

1. [Node.js](https://nodejs.org/)（LTS）を入れる
2. `start.bat` をダブルクリック（初回だけ Electron のダウンロードで数分かかります）

起動すると画面右端に小さなランチャーが出ます（上の「•••」をつまむと移動できます）。タスクトレイにも常駐します。

## 使い方

| やりたいこと | ランチャー | キーボード |
|---|---|---|
| 今の画面を止めて書く | 静止で書く | Ctrl+Alt+S |
| 動いている画面に重ねて書く | 重ねて書く | Ctrl+Alt+D |
| 書く ⇔ 下のアプリを操作（重ね書き中） | ツールバー「操作」／ランチャー「書く」 | Ctrl+Alt+A |
| 閉じる（書き込みは消えます） | ✕ | Esc / Ctrl+Alt+X |

Esc は、何かを選択している間はまず選択を外します。

- ペンは筆圧で太さが変わります。ペンの尻（消しゴム側）かサイドボタンを押しながら書くと消しゴムになります。
- ペンは常に書く、指は常に操作です（指1本では書けません）。ペンを使っている間と直後は、手のひらや指のタッチは無視されます。
- 「保存」で PNG を `ピクチャ\ScreenInk` に保存し、同時にクリップボードにもコピーします（そのまま貼り付け可）。
- 「静止」「ライブ」ボタンは、書き込みを残したままモードを切り替えます。
- マルチモニターでは、マウスカーソルのある画面が対象です。
- ツールバー内のキー: Ctrl+Z 戻す / Ctrl+Y 進む / Ctrl+S 保存 / Ctrl+C コピー / Ctrl+V 貼り付け / Delete 削除 / P ペン / H マーカー / E 消しゴム / V 選択

## 拡大縮小と無限キャンバス（静止モード）

- 2本指のピンチで拡大縮小、2本指のドラッグで移動します。
- 縮小するとキャプチャの外側に白紙が広がり、そこにも書けます。キャプチャは白紙の上に置かれた1枚の画像です。
- 線はベクターで持っているので、拡大してもぼやけません。消しゴムは線を分割して消します。
- ツールバーの「全体」（Ctrl+1）で書き込みと画像のすべてを表示、「100%」（Ctrl+0）で等倍に戻します。
- マウスの場合: Ctrl+ホイールで拡大縮小、ホイールで移動、中ボタンのドラッグか Space+ドラッグで移動。
- ライブモードは等倍の重ね書きのままです（ピンチしても拡大しません）。

## 貼り付けと画像（静止モード）

- クリップボードの画像を Ctrl+V かツールバーの「貼付」で貼り付けます。位置は今見えている範囲の中央です。
- 「＋撮影」で別の画面をもう1枚撮れます。書き込み画面がいったん隠れるので、撮りたい画面を出してから
  ランチャーの「撮る」（または Ctrl+Alt+S）を押してください。今ある画像の右隣に並びます。
- 画像も線も「もの」として選択できます。選択すると青い枠が出て、枠の中をドラッグで移動、四隅で拡大縮小、
  メニューの「削除」か Delete キーで削除できます。ペン・指・マウスのどれでも掴めます。
- 選び方: 指でタップ（線・貼り付けた画像）、またはツールバーの「選択」（V）でクリック／囲んで複数選択。
  最初に撮った画面そのものは、うっかり動かさないよう「選択」ツールでクリックしたときだけ選択されます。
- 何もない所をタップするか Esc で選択が外れます。どの操作も「戻す」で取り消せます。
- 画像は常に線の下に描かれます。テキストの貼り付けには未対応です。

## インクジェスチャー（ペンだけで消す・選ぶ）

Microsoft Journal にならった、道具を持ち替えずにペンだけで行う操作です。「ペン」ツールで書いた線にだけ働きます。

| 書き方 | 起きること |
|---|---|
| 線や貼り付けた画像の上を、素早くぐしゃぐしゃと往復する | その下のものが消える（スクラッチアウト） |
| 線や貼り付けた画像を、ぐるっと囲む | 囲んだ瞬間に中のものが選択される（投げ縄） |
| 線や貼り付けた画像の上で、ペンを動かさず 0.5 秒押す | それが選択される。押したまま動かすと移動 |
| 指でタップ | 線や貼り付けた画像を選択。何もない所なら選択を外す |

選択したあとは、枠の中をドラッグで移動、四隅で拡大縮小、メニューで「コピー」「削除」ができます（Ctrl+C / Delete）。
コピーしたものは Ctrl+V で線のまま貼り付けられ、ほかのアプリには画像として貼り付けられます。

普通の線が勝手に消えたり選択されたりしないよう、判定は控えめにしてあります。

- 消す・囲む対象が下に無ければ、ぐしゃぐしゃも丸もそのまま線として残ります。
- スクラッチアウトは、2往復半以上の素早い往復で、線の6割以上を覆ったときだけ働きます。
  長い線の一部をこすっただけ、1回なぞっただけ、ゆっくりした往復では消えません。
- 囲んで選択されるのは、書いてから1秒以上たったものだけです（書いた直後に丸で囲む書き込みを邪魔しません）。
  丸を書きたかったのに選択になったときは、メニューの「線として残す」か「戻す」で丸が線として残ります。
- 最初に撮った画面そのものは、ジェスチャーでは消えも選択されもしません。
- どの操作も「戻す」（Ctrl+Z）で取り消せます。

しきい値を変えたいときは `overlay.js` の `HOLD_MS` / `LASSO_MIN_AGE` / `SCRATCH_SPEED` と、`ink-geom.js` の
`isScratch` / `scratchTargets` / `isLoop` を調整してください。

## テスト

- `npm test` … 幾何計算の単体テスト
- `npm run test:e2e` … 実際の画面を Electron で開き、ペン・指・マウスの入力を合成して確認します。
  `SCALE=1.5` を付けると拡大率 150% を模擬します。
- `npm run test:main` … 実際のアプリを起動し、キャプチャの大きさ・位置、モード切り替え、追加撮影を確認します
  （数秒間、全画面の書き込み画面が出ます）。Surface ではまずこれを実行すると、拡大率によるずれの有無が分かります。
- 筆圧・ペンのボタン・実際の指の操作は、実機で手を動かして確認してください。

## exe にする

`npm run pack` で `dist` フォルダに ScreenInk.exe ができます。
このexeを「設定 → Bluetoothとデバイス → ペンとWindows Ink」でペンのショートカットボタンに割り当てると、
ペンのボタンを押すだけでキャプチャして書き始められます（起動中にもう一度呼ばれると即キャプチャする作りです）。

## 調整

- ショートカット: `main.js` 冒頭の `KEYS`
- 色・太さ: `overlay.html` のボタン（`data-color` / `data-size`）
- キャプチャに自分のツールバーが写り込む場合: `main.js` の `HIDE_WAIT_MS` を大きく
